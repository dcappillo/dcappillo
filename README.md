### Derek Cappillo

I'm a math nerd with a research background who builds things. I have a math degree and a master's in evaluation and measurement from Kent State, and I spent 15 years using them in places most math majors don't end up. That meant federal program evaluation for NASA, curriculum design, and a lot of years in front of a classroom.

Teaching taught me to explain hard things to people who didn't ask to learn them. Evaluation taught me to validate and replicate results. At some point I started building things after the kids went home, and the projects got bigger than the reasons I started them.

That's what's here.

#### What I've built

| Project | What it is | Stack |
|---|---|---|
| [**Olympus**](https://cappillolympus.netlify.app) | My own JARVIS, built on Hermes Agent. It sorts every task into tiers and runs the big ones through single-job "hats" named after Greek gods, each on its own model, with an append-only log and a script that audits it. No claim counts without evidence. [Explore the diagram.](https://cappillolympus.netlify.app) | Hermes Agent, Ollama, Claude Code, Codex, Gemini |
| [**Capjobs**](https://github.com/dcappillo/Capjobs) | A job-listing pipeline. Pulls from the Adzuna and USAJobs APIs, drops exclusions and duplicates, flags listings that need an active clearance, scores the rest against weighted keywords, and writes one ranked CSV. | Python |
| [**4rdle**](https://github.com/dcappillo/4rdle) | A combinatorics search for Wordle word sets with no repeated letters (25,456,119 four-word sets), plus an analysis of which opener is actually best. Coverage ties 1,247 sets. Letter position breaks the tie. | JavaScript, Python |
| [**Cap Tunes**](https://github.com/dcappillo/CapTunes) | A Spotify-style Android player for your own music, from your phone or a self-hosted Navidrome server. Smart mixes, synced lyrics, and a yearly Wrapped built from on-device listening history. | Kotlin, Jetpack Compose, Media3 |
| [**Cap Flix**](https://github.com/dcappillo/cap-flix) | The video counterpart: an Android client for a personal Jellyfin server, with libVLC handling playback. | Kotlin, Jetpack Compose, libVLC |
| [**CapFootball**](https://github.com/dcappillo/Dcap-Football) | A 32-team football GM sim with a headless test suite that plays full seeded seasons. Coaching hires, contract negotiations, the draft, injuries, playoffs and Black Monday. [Play it.](https://luminous-begonia-f68904.netlify.app/) | JavaScript |
| [**Baltiword**](https://github.com/dcappillo/Baltiword) | A daily six-letter word game where every answer is Baltimore. [Play it.](https://baltiword.netlify.app) | React, Vite |
